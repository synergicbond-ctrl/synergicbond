5.4 Numbering with several kinds of locant

Example 31 Direct application

Name the hydroxy-ketone.

Show solution
  1. Groups: C=O (ketone), C=C, OH. Principal group: ketone (above alcohol).
  2. Six-carbon chain containing C=O, C=C and C–OH.
  3. Numbering: the C=O must have the lowest locant: from the CH₃CO end, C=O is 2 (from the other end it would be 5).
  4. Then C=C = 3 (C3=C4), OH on C5 as hydroxy.

5-Hydroxyhex-3-en-2-one.

Example 32 Standard

Name the compound.

Show solution
  1. Acid is the principal group: COOH = C1.
  2. Chain: C1 COOH, C2=C3, C4 CH(OH), C5 CH₃.
  3. Principal group fixes the direction (C1 = COOH carbon). Then ene = 2, hydroxy = 4.

4-Hydroxypent-2-enoic acid (the E/Z isomer would carry a descriptor in front).

Example 33 Standard

Name the compound.

Show solution
  1. Alcohol is the principal group. Five-carbon chain with OH and C=C.
  2. OH lowest: from the CH₃ end, OH = 2 (other end 4).
  3. Then C=C = 4 (C4=C5).

Pent-4-en-2-ol — the double bond gets a high locant because the OH has priority.

Example 34 Standard

Name the compound.

Show solution
  1. Groups: ketone (principal) and OH (hydroxy prefix).
  2. Seven-carbon chain. The C=O lowest: C2 from the right in the drawing as written; counting that way the methyl is on C4 and OH on C6.
  3. Check the other direction: C=O would be 6, so the first choice is forced.

6-Hydroxy-4-methylheptan-2-one. Alphabetical order: hydroxy (h) before methyl (m).

Example 35 Standard

Name the compound.

Show solution
  1. Acid is the principal group (carbon 1); the ketone becomes oxo.
  2. Chain: C1 COOH, C2, C3, C4 C=O, C5 CH₃.

4-Oxopentanoic acid (levulinic acid).

Example 36 Direct application

Name the compound.

Show solution
  1. Ketone above amine: ketone is the suffix, amine becomes amino.
  2. Ketone lowest locant: C2; amino on C4.

4-Aminobutan-2-one.

Example 37 Standard

Name the compound.

Show solution
  1. Principal group: ketone (above alcohol). Chain: C1 CH₃, C2 C=O, C3 CH₂, C4=C5, C6 CH₂OH — six carbons.
  2. C=O gets 2 (from the other end it would be 5). Then C=C at 4, hydroxy at 6.

6-Hydroxyhex-4-en-2-one.
