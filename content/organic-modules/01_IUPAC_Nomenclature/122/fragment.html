Level 3 · E. Encoded-answer problems

Several examination papers combine a naming task with a code: "let M be the sum of all printed locants, N the number of carbon atoms in the prefixes, E the number of different prefixes; find 100M + 10N + E". The method never changes: write the correct name first, then read M, N, E from it. Remember that a numbering error changes M, so the code is a built-in check.

Q198 Integer

For the alkene shown, write the IUPAC name. Let M = sum of every printed locant (including the double-bond locant), N = total carbon atoms in carbon-containing prefixes, E = number of different prefixes. Find 100M + 10N + E.

Q199 Integer

For the substituted benzoic acid shown, number the ring for the lowest locant set. Let M = sum of all printed locants including the internal locant of 1-methylethyl, N = carbon atoms in carbon-containing prefixes, E = number of different prefixes. Find 100M + 10N + E.

Q200 Integer

For the cyclohexene shown number the ring from the double bond and use the first point of difference to fix the direction. Let M = sum of all locants in the full name (count the double-bond locant 1), N = carbon atoms in carbon-containing prefixes, E = number of different prefixes. Find 100M + 10N + E.

Q201 Integer

For the compound shown let M = sum of all printed locants and E = number of different prefixes. Find 100M + E.

Q202 Integer

For the alkane shown let M = sum of all locants, G = number of substituent groups (each methyl or ethyl counted separately) and E = number of different substituents. Find M·G + E.

Q203 Integer

For the haloalkane shown find 10·(sum of locants) + (number of different prefixes).
