3. Acidity of benzoic acids

Electron-withdrawing groups increase acid strength and electron-donating groups decrease it, and the effect is strongest in the ortho and para positions (Ref. [1], Table 20-4 text).

Example 3 · Acidity · electronic effects

Increasing acidity (lower pKa is stronger): p-methoxybenzoic acid (4.46) < benzoic acid (4.19) < p-nitrobenzoic acid (3.41)

The methoxy group donates by resonance and lowers acidity. The nitro group withdraws by resonance and by induction, so it increases acidity. No ortho bulk is present, so SIR is not the cause of these orders.

Source: Ref. [1], Table 20-4.

Example 4 · Acidity · SIR claim, contested

Contested: 2,6-dimethylbenzoic acid is often described as stronger than benzoic acid because SIR twists the carboxyl group.

A 2000 study of ortho-methyl benzoic acids reports SIR in the anion as well as in the neutral acid, so the SIR explanation for the acidity is not established. No measured pKa from this source is given here.

Source: Böhm (2000), Chem. Eur. J. 6, 3391. Read from the abstract only; full text not checked.

Example 5 · Basicity · contrast (stepwise N-methylation)

Increasing basicity: aniline (4.60) < N-methylaniline (4.79) < N,N-dimethylaniline (5.06)

Each added methyl group adds a small +I donation to nitrogen, so the basicity rises in steps. No ortho group is present, so SIR does not enter.

Source: Ref. [1], Table 19-3.

Example 6 · Basicity · contrast (para substituents on aniline)

Increasing basicity: p-bromoaniline (3.8) < aniline (4.60) < p-methoxyaniline (5.3)

Bromine withdraws electron density (−I, weak +M), so the base is weakened. Methoxy donates by resonance (+M), which raises basicity. Both are para, so the substituent acts on the nitrogen through the ring, with no ortho bulk.

Source: Ref. [1], Table 19-3.

Example 7 · Acidity · contrast (nitrobenzoic acid isomers)

Increasing acidity (lower pKa is stronger): m-nitrobenzoic acid (3.47) < p-nitrobenzoic acid (3.41) < o-nitrobenzoic acid (2.16)

Ref. [1] states that the nitro group has a larger effect in the ortho and para positions than in the meta position. The ortho value is the lowest pKa in this set. This file does not attribute the ortho value to SIR.

Source: Ref. [1], Table 20-4.
