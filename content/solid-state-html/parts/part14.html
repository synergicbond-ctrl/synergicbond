◆Concept

This part first lists nearest-neighbour distances and then develops successive coordination shells for SC, FCC and BCC.

1. Distance from a Lattice Vector

∑Formula

For a cubic lattice vector a[u,v,w], d = a√(u²+v²+w²).

◆Concept

A coordination shell contains all equivalent neighbours at the same distance from the reference atom.

5. Coordination Number

★First-shell CN

SC = 6, BCC = 8, FCC/CCP = 12. Coordination number normally means first-neighbour count unless a shell number is explicitly stated.

⚠JEE Advanced traps & edge cases

  • Do not add different-distance shells together when asked for coordination number.
  • For FCC, the nearest-neighbour distance is a/√2, not a.
  • For BCC, nearest neighbours are the body-centre/corner pairs at √3 a/2.

▶Solved examples

Worked example 1

Example 1 — Source-style

An FCC metal has third-neighbour distance 400 pm. Find atomic radius.

  1. d₃=√(3/2)a=400 pm.
  2. For FCC, a=2√2 r.
  3. Thus d₃=√(3/2)(2√2 r)=2√3 r.
  4. r=400/(2√3).

r = 200/√3 ≈ 115.5 pm.

Worked example 2

Example 2 — Multi-correct

For BCC, identify correct pairs: (A) 1st shell 8 at √3a/2; (B) 2nd shell 6 at a; (C) 3rd shell 12 at √2a; (D) CN=12.

  1. A, B and C match the shell table.
  2. Coordination number is first-shell count = 8.

Correct: A, B, C.
