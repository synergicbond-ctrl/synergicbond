Part 9 · Trivial names and reagent-type compounds

Definition. A trivial name is a retained historical name that does not follow the substitutive rules. The tables list the trivial names used in problems on reagents, products, monomers and named reactions. Each table pairs the trivial name, the systematic name and the structure; every systematic name in a table was parsed back to the structure shown. A tilde in the IUPAC column marks a name that was accepted by convention but is outside the parser's grammar.
