Trap Gattermann–Koch does not work on phenol: the phenol complexes with AlCl3 and CO/HCl is not electrophilic enough; use Gattermann (HCN/HCl) or Reimer–Tiemann. The Gattermann–Koch electrophile H–C≡O+ cannot be made from HCOCl, which decomposes (CO + HCl), which is why high-pressure CO + HCl is used.
Key idea Carbon count: all four install one carbon (CHO) except Houben–Hoesch which adds the whole RCO unit (carbon count of R + 1).
Example 37 Main

Choose the formylation

Which reagent set converts (a) toluene → p-tolualdehyde, (b) phenol → salicylaldehyde, (c) anisole → p-anisaldehyde, (d) resorcinol → 2,4-dihydroxyacetophenone?

Show solution
  1. (a) Gattermann–Koch: CO, HCl, AlCl3/CuCl. (b) Reimer–Tiemann: CHCl3/NaOH (or Gattermann: HCN/HCl, ZnCl2). (c) Vilsmeier–Haack (DMF/POCl3) or Gattermann. (d) Houben–Hoesch: CH3CN, HCl, ZnCl2, then H2O.
