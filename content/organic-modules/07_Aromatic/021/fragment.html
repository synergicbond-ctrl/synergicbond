19. Multistep synthesis of substituted benzenes: how to plan

A synthesis problem asks for a target with several groups in a particular relationship. The tools are the directing rules, the order of events, the interconversion of groups, and protecting/blocking strategies. Work backwards from the target (retrosynthesis) and ask at each stage: "which group directs the last entering group into this position?"

19.1 The seven rules of thumb

  • 1. Order of introduction matters. A group introduced first determines where the next goes. Choose the order that makes the existing group direct the new one where you want it.
  • 2. Meta from a meta-director; ortho/para from an o/p-director. m-Bromonitrobenzene: nitrate first, then brominate. p-Bromonitrobenzene: brominate first, then nitrate (separate p from o).
  • 3. Convert a group in the middle to change its directing character. –CH3 (o/p) → –COOH (meta) with KMnO4; –NO2 (meta) → –NH2 (o/p) with Sn/HCl; –COCH3 (meta) → –CH2CH3 (o/p) with Clemmensen.
  • 4. Do Friedel–Crafts reactions first. Both alkylation and acylation fail on rings that already carry –NO2, –COR, –SO3H or basic –NH2.
  • 5. Moderate or protect strongly activating groups. Acetylate –NH2 to prevent over-substitution/oxidation; use a sulphonic acid or t-butyl group as a blocking group to force substitution at the ortho position.
  • 6. Use diazonium chemistry for groups EAS cannot install (F, I, CN, OH, H) or to place a group in a position forbidden by the rules; deaminate with H3PO2 to remove an NH2 director.
  • 7. Separate isomers by physical properties: para isomers often have higher melting points and lower solubility (crystallise), while ortho isomers with intramolecular H-bonds (o-nitrophenol, salicylaldehyde) are steam-volatile.

19.2 Worked syntheses (from benzene unless stated)

Example 41 Main

The positional pair

Synthesise (a) m-bromonitrobenzene (b) p-bromonitrobenzene (c) o-bromonitrobenzene (d) m-chloroaniline (e) p-chloroaniline.

Show solution
  1. (a) Benzene → HNO3/H2SO4 → nitrobenzene (meta director) → Br2/FeBr3 → m-bromonitrobenzene. Nitrate first.
  2. (b) Benzene → Br2/FeBr3 → bromobenzene (o/p director) → HNO3/H2SO4 → mixture of o- and p-bromonitrobenzene; the p-isomer (higher m.p. 399 K, crystallises) is separated. Brominate first.
  3. (c) Same mixture as (b); o-isomer (m.p. 316 K) from the filtrate (or by sulphonation of bromobenzene to block para: PhBr → H2SO4 → p-BrC6H4SO3H → HNO3 → o-nitro → dilute H2SO4, steam).
  4. (d) Nitrobenzene → Cl2/FeCl3 → m-chloronitrobenzene → Sn/HCl (or Fe/HCl) → m-chloroaniline.
  5. (e) Chlorobenzene → HNO3/H2SO4 → separate p-chloronitrobenzene → Sn/HCl → p-chloroaniline.

Example 42 Main

Using side-chain oxidation as a group switch

Synthesise (a) m-nitrobenzoic acid (b) p-nitrobenzoic acid (c) m-bromobenzoic acid (d) p-bromobenzoic acid from toluene or benzene.

Show solution
  1. (a) Toluene → KMnO4/OH−, then H3O+ → benzoic acid (m-director) → HNO3/H2SO4 → m-nitrobenzoic acid.
  2. (b) Toluene → HNO3/H2SO4 → separate p-nitrotoluene → KMnO4/OH−; H3O+ → p-nitrobenzoic acid. (Oxidise after nitration so that CH3, an o/p-director, controls nitration.)
  3. (c) Toluene → oxidation → benzoic acid → Br2/FeBr3 (excess Fe) → m-bromobenzoic acid.
  4. (d) Toluene → Br2/FeBr3 → separate p-bromotoluene → KMnO4, OH−; H3O+ → p-bromobenzoic acid.
Example 43 Adv

Making 1,3,5-tribromobenzene and m-bromotoluene

Give the sequences for (a) 1,3,5-tribromobenzene from benzene (b) m-bromotoluene from toluene.

Show solution
  1. (a) Benzene → HNO3/H2SO4 → nitrobenzene → Sn/HCl → aniline → Br2/H2O → 2,4,6-tribromoaniline → NaNO2/HCl, 273 K; then H3PO2 → 1,3,5-tribromobenzene. (Direct bromination of benzene never reaches the 1,3,5-pattern.)
  2. (b) Toluene → HNO3/H2SO4 → p-nitrotoluene (separate) → Sn/HCl → p-toluidine → Ac2O → p-acetotoluidide → Br2, AcOH → 2-bromo-4-methylacetanilide (Br ortho to the stronger activator NHAc, meta to CH3) → H3O+, Δ → 2-bromo-4-methylaniline → NaNO2/HCl; H3PO2 → m-bromotoluene.
Example 44 Adv

Moderate or block

Give a sequence for (a) p-nitroaniline from aniline (b) o-nitroaniline from aniline (c) 2,6-dibromoaniline from aniline.

Show solution
  1. (a) Aniline → Ac2O → acetanilide → HNO3/H2SO4, 283 K → p-nitroacetanilide (major) → H3O+, Δ → p-nitroaniline.
  2. (b) Acetanilide → conc. H2SO4 (or ClSO3H) → p-acetamidobenzenesulphonic acid (para blocked) → HNO3/H2SO4 → nitro ortho to NHCOCH3 → dilute H2SO4, Δ (removes both acetyl and SO3H) → o-nitroaniline.
  3. (c) Acetanilide → conc. H2SO4 (para block) → Br2 (excess; both ortho positions) → H3O+, Δ (removes Ac and SO3H) → 2,6-dibromoaniline.

Example 45 Adv

Drug molecules

Outline the synthesis of (a) paracetamol from phenol (b) sulphanilamide from aniline (c) aspirin from phenol (d) picric acid from phenol.

Show solution
  1. (a) Phenol → dilute HNO3 → p-nitrophenol (separate from ortho by steam distillation: o-isomer distils) → Sn/HCl → p-aminophenol → Ac2O (acetylates N preferentially) → paracetamol (N-(4-hydroxyphenyl)acetamide).
  2. (b) Aniline → Ac2O → acetanilide → ClSO3H → p-acetamidobenzenesulphonyl chloride → NH3 → p-acetamidobenzenesulphonamide → H3O+, Δ → sulphanilamide (4-aminobenzenesulphonamide).
  3. (c) Phenol → NaOH → sodium phenoxide → CO2, 400 K, 4–7 atm; H3O+ → salicylic acid → Ac2O (H+) → aspirin (2-acetoxybenzoic acid).
  4. (d) Phenol → conc. H2SO4 (di-sulphonation at 2,4) → conc. HNO3 (replaces SO3H by NO2, and nitrates) → 2,4,6-trinitrophenol (picric acid); the sulphonation first avoids oxidation of phenol by nitric acid.

Example 46 Adv

When the order matters, a worked comparison

Compare the routes to 4-bromo-2-nitrotoluene and 2-bromo-4-nitrotoluene from toluene.

Show solution
  1. 4-Bromo-2-nitrotoluene: toluene → Br2/FeBr3 → separate p-bromotoluene → HNO3/H2SO4: CH3 (stronger activator than Br) directs ortho to itself, i.e. C2: 4-bromo-2-nitrotoluene.
  2. 2-Bromo-4-nitrotoluene: toluene → HNO3/H2SO4 → separate p-nitrotoluene → Br2/FeBr3: CH3 directs ortho to itself, which is meta to NO2: both groups agree → 2-bromo-4-nitrotoluene (ring is deactivated, so heat or excess catalyst is needed).
  3. The same two groups, in two orders, give two different isomers: this is the standard demonstration of "order of introduction".

19.3 Retrosynthetic flowchart

Ask these questions in order for each bond to the ring that you need to make:

  • 1. Is the target group (or its precursor) o/p- or m-directing relative to the groups already present at that position's neighbours? Decide which group should be introduced first.
  • 2. Can the ring tolerate the reaction? (FC alkylation/acylation fail on rings with m-directors or NH2; nitration oxidises phenol/aniline.)
  • 3. Do two groups need to be meta although both are o/p directors? Use the NH2/N2+ route or a blocking strategy.
  • 4. Is a group needed that EAS cannot install (F, I, CN, OH)? Use diazonium.
  • 5. Is a straight-chain alkyl needed? Acylate then reduce.
  • 6. Does the target need a cine/meta relationship? Consider benzyne.
