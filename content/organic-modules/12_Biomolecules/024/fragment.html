  • mRNA (messenger, ≈ 5 % of cell RNA): complementary copy of a gene; read in triplets (codons). tRNA (transfer, 73–93 nt, ≈ 15 %): cloverleaf, an anticodon loop pairs with the codon; 3′-CCA end carries the amino acid. rRNA (ribosomal, ≈ 80 %): with proteins forms ribosomes (peptide bond formation is catalysed by rRNA: the ribosome is a ribozyme).

Central dogma

  • DNA → (replication) → DNA; DNA → (transcription, RNA polymerase) → mRNA; mRNA → (translation, ribosome, tRNA) → protein.
  • Replication is semiconservative: each daughter duplex has one old and one new strand (Meselson–Stahl, 15N/14N density-gradient experiment, 1958). DNA polymerase synthesises 5′→3′ only (adds dNTP to a 3′-OH) and needs a primer; the leading strand is made continuously, the lagging strand in Okazaki fragments (≈ 1000–2000 nt in bacteria, 100–200 nt in eukaryotes) joined by DNA ligase. Helicase unwinds, primase lays RNA primers, topoisomerase relieves supercoiling.
  • Transcription: RNA polymerase copies the template strand (3′→5′) into mRNA (5′→3′), which has the same sequence as the coding strand with U in place of T.
  • Translation: mRNA codon (3 bases) → amino acid via tRNA anticodon (antiparallel pairing). Start codon AUG (Met), stop codons UAA, UAG, UGA.

The genetic code

  • 43 = 64 codons: 61 sense (coding for 20 amino acids) + 3 stop. The code is degenerate (most amino acids have several codons), non-overlapping, comma-free and nearly universal.
  • Met (AUG) and Trp (UGG) have a single codon each; Leu, Ser and Arg have six; Ile has three; five (Val, Pro, Thr, Ala, Gly) have four; nine (Phe, Tyr, His, Gln, Asn, Lys, Asp, Glu, Cys) have two. Check: 1 + 1 + 18 + 18 + 20 + 3 = 61.
  • A point mutation can be silent (same amino acid), missense (different amino acid, e.g. sickle-cell Glu6Val) or nonsense (stop codon). Insertion or deletion of 1 or 2 nucleotides causes a frameshift.
Formula Number of possible nucleotide sequences of length n: 4n (a gene of 300 nt: 4300). Number of possible peptides of length n: 20n. Number of codons that can code for a peptide of n residues (maximum): ≤ 6n.
Example 64 Main

Chargaff's rule

A double-stranded DNA contains 28 % thymine. Find the percentages of A, G and C.

Show solution
  1. A = T = 28 %. G + C = 100 − 56 = 44 %, so G = C = 22 %.
Example 65 Main

Complementary strand and mRNA

The template strand of a gene reads 3′-TACGGATTC-5′. Write (a) the coding strand, (b) the mRNA, (c) the peptide formed (AUG Met, CCU Pro, AAG Lys).

Show solution
  1. (a) Coding strand is complementary to the template: 5′-ATGCCTAAG-3′.
  2. (b) mRNA has the coding-strand sequence with U: 5′-AUGCCUAAG-3′.
  3. (c) AUG = Met, CCU = Pro, AAG = Lys: Met–Pro–Lys.
Example 66 Adv

Hydrogen bonds and melting

Two 20-bp duplexes: duplex X has 4 G–C pairs, duplex Y has 14 G–C pairs. Count the H-bonds and predict which has the higher Tm. Use the Wallace rule per strand.

Show solution
  1. X: 4 GC (12 H-bonds) + 16 AT (32) = 44; Y: 14 GC (42) + 6 AT (12) = 54.
  2. Wallace: X: 2(16) + 4(4) = 48 °C; Y: 2(6) + 4(14) = 68 °C. Y melts higher (the rule is only valid for < 14 nt, so these are rough).
Example 67 Adv

Semiconservative replication

E. coli grown for many generations in 15N medium is transferred to 14N medium. After 3 generations, what fraction of the DNA duplexes is (a) hybrid 14N/15N, (b) fully light, (c) fully heavy?

Show solution
  1. After n generations there are 2n duplexes; 2 contain one 15N parental strand (hybrid).
  2. n = 3: 8 duplexes: 2 hybrid (25 %), 6 fully light (75 %), 0 fully heavy.
Example 68 Adv

PCR amplification

A PCR with 100 % efficiency starts from one DNA molecule. How many molecules after 30 cycles?

Show solution
  1. 230 = 1.07 × 109 (≈ a billion-fold).
Example 69 Adv

Length and mass of DNA

A plasmid has 5000 bp. Estimate (a) its contour length (3.4 Å per bp), (b) its molar mass (650 g mol−1 per bp), (c) the number of helical turns (10 bp/turn).

Show solution
  1. (a) 5000 × 3.4 Å = 17 000 Å = 1.7 μm.
  2. (b) 5000 × 650 = 3.25 × 106 g mol−1.
  3. (c) 5000/10 = 500 turns.
Example 70 Adv

Nucleic acid hydrolysis

Which of the following are products of (i) complete acid hydrolysis of RNA, (ii) alkaline hydrolysis of DNA: ribose, deoxyribose, adenine, uracil, thymine, phosphoric acid, intact DNA?

Show solution
  1. (i) RNA, complete acid hydrolysis: ribose, adenine (and G, C), uracil, phosphoric acid.
  2. (ii) DNA is stable in cold alkali: intact DNA (no hydrolysis; deoxyribose, thymine not released).
Example 71 Main

DNA vs RNA

State three structural differences and one functional difference.

Show solution
  1. Sugar (deoxyribose vs ribose), base (thymine vs uracil), strandedness (double vs single). Function: DNA stores genetic information; RNA carries out its expression (messenger, adaptor, ribosomal).
