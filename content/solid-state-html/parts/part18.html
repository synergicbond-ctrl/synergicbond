◆Concept

The source next counts tetrahedral and octahedral voids, locates them in FCC and HCP, and tracks them layer by layer.

1. Universal Close-Packing Count

◆Concept

For N close-packed spheres:

∑Formula

Number of octahedral voids = N; tetrahedral voids = 2N.

2. FCC / CCP Void Locations

◆Concept

An FCC conventional cell contains 4 close-packed spheres, therefore 4 octahedral voids and 8 tetrahedral voids.
VoidFractional coordinates / locationEffective number
OctahedralBody centre (1/2,1/2,1/2) + 12 edge centres shared by 4 cells1 + 12/4 = 4
TetrahedralAll 8 combinations (x,y,z) with x,y,z ∈ {1/4,3/4}8

3. How the Voids Arise Between Two Close-Packed Layers

◆Concept

A tetrahedral void is surrounded by 4 spheres. An octahedral void is surrounded by 6 spheres. A triangular hole is a 2D depression; it becomes a 3D tetrahedral or octahedral void only after the next layer is added.

4. HCP Void Count and Layer Locations

◆Concept

The conventional HCP cell contains 6 spheres, so it contains 12 tetrahedral and 6 octahedral voids.
  • Three effective octahedral voids occur between the lower A and middle B layers, and three between B and upper A.
  • A careful boundary count gives 6 effective tetrahedral voids in each A–B interval, hence 12 total.
  • The source tracks void planes at fractional heights such as h/8, 2h/8, 3h/8, …, 7h/8 to visualize alternating tetrahedral and octahedral sites.

5. Occupancy-to-Formula Method

◆Concept

If a close-packed array contains N host anions, then it provides N octahedral and 2N tetrahedral sites. Multiply those counts by the occupied fractions to obtain cation number and hence the formula.

⚠JEE Advanced traps & edge cases

  • A triangular hole is not the same as a tetrahedral void.
  • FCC edge-centred octahedral voids contribute 1/4 each.
  • “N tetrahedral voids” is wrong for a close-packed array; there are 2N.

▶Solved examples

Worked example 1

Example 1

A CCP anion array contains 200 anions. How many TV and OV are available?

  1. TV=2N.
  2. OV=N.

TV=400; OV=200.

Worked example 2

Example 2 — Formula

A close-packed X array has 25% of TV and 50% of OV occupied by M. Find M:X.

  1. TV contribution = 0.25×2N = 0.5N.
  2. OV contribution = 0.50×N = 0.5N.
  3. Total M=N.

M:X = 1:1, so MX.
