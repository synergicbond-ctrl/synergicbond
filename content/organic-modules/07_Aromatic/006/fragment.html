4. Nomenclature of benzene derivatives

IUPAC retains many common names. The ring is the parent when it carries the senior functional group as a substituent attached directly to it. Numbering follows lowest locants, and ties are broken alphabetically.

  • Ortho, meta, para (o, m, p) are used only for disubstituted benzenes: 1,2; 1,3; 1,4.
  • In the IUPAC name, benzene is the parent unless a retained name is used; for polysubstituted rings the lowest locant set is assigned first to the principal group (if the name is a retained one that includes the group such as phenol, benzoic acid), then by the lowest-set-of-locants rule, then alphabetical order.
  • Prefix vs. suffix: −COOH, −SO3H, −CHO, −COR, −CN, −OH, −NH2 (in decreasing seniority). If a higher group is present, −NO2, −X and −R are only prefixes.

Example 5 Main

Name these

(a) C6H5CH2Cl (b) ClC6H4CH3-p (c) the compound with CH3, NO2 and Br on a ring at 1, 2, 4 with CH3 at C1, NO2 at C2 and Br at C4 (d) the dibromobenzene whose ring carbons show only 3 13C signals.

Show solution
  1. (a) Benzyl chloride, (chloromethyl)benzene. The Cl is on the side chain, not the ring, so it is not a chlorotoluene.
  2. (b) 4-Chlorotoluene (p-chlorotoluene, 1-chloro-4-methylbenzene).
  3. (c) 4-Bromo-2-nitrotoluene (1-methyl-4-bromo-2-nitrobenzene is not used; alphabetical order bromo < nitro in the prefix; CH3 is C1 because toluene is the parent).
  4. (d) o-Dibromobenzene (1,2) has 3 ring carbon signals: C1/C2, C3/C6, C4/C5. (p-Dibromobenzene has 2; m-dibromobenzene has 4.)
