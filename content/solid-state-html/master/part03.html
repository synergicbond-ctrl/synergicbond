3.3 Coordination number and neighbour shells

The coordination number of an atom in a monatomic crystal is the number of nearest neighbours at the shortest centre-to-centre distance. Successive neighbour shells occur at larger discrete distances.

LatticeFirst shellSecond shellThird shell
SC6 at aaa12 at 2a\sqrt2a2​a8 at 3a\sqrt3a3​a

The FCC and HCP lattices both have coordination number 12 and the same maximum packing fraction, but they differ in the stacking sequence of close-packed layers.

3.5 Formula determination from fractional occupancy

Count every species independently. Site occupancy means the fraction of a set of crystallographically equivalent sites that is actually occupied.

NX=∑snsfsqsN_X=\sum_s n_s f_s q_sNX​=s∑​ns​fs​qs​

For species X, nsn_sns​ is the number of sites of type sss per cell, fsf_sfs​ the boundary contribution and qsq_sqs​ the occupancy fraction.

Worked example

Occupancy problem

A cubic cell has A on all corners, B on all face centres, and C on one-half of the twelve edge centres. Determine the formula.

  1. A: 8(1/8)=18(1/8)=18(1/8)=1.
  2. B: 6(1/2)=36(1/2)=36(1/2)=3.
  3. C: 12(1/4)(1/2)=3/212(1/4)(1/2)=3/212(1/4)(1/2)=3/2.
  4. Ratio 1:3:1.51:3:1.51:3:1.5; multiply by 2.
The empirical formula is A2B6C3\mathrm{A_2B_6C_3}A2​B6​C3​.

3.6 Atom-removal and surface-counting problems

When a geometric operation removes atoms from a finite conventional cell, count only the fractions originally belonging to that cell. A line or plane can include corners, edge centres, face centres and internal sites.

5
Worked example

Removing an FCC face

All atoms lying on one complete face of an FCC conventional cell are removed from that cell. What is the decrease in the atom count assigned to the cell?

  1. The chosen face has four corner atoms, each contributing 1/81/81/8 to the selected three-dimensional cell.
  2. It has one face-centre atom contributing 1/21/21/2.
  3. Decrease =4(1/8)+1/2=1=4(1/8)+1/2=1=4(1/8)+1/2=1.
The cell's assigned atom count decreases by 1, from 4 to 3.
Finite object versus periodic crystal

Removing one face from a drawn cell is a bookkeeping exercise. In an infinite periodic lattice, the same boundary sites are shared with neighbouring cells, so the physical operation must be defined carefully.

3.7 Surface gaps and coordinate-tracking algorithm

In BCC, corner atoms do not touch along an edge. The centre-to-centre edge separation is aaa, while each sphere has diameter 2r=3a/22r=\sqrt3a/22r=3​a/2. The surface gap is therefore positive.

gedge=a−2r=a(1−32)g_{edge}=a-2r=a\left(1-\frac{\sqrt3}{2}\right)gedge​=a−2r=a(1−23​​)

For atom-removal problems, first write the fractional coordinates of every occupied site on the specified line or plane. Then subtract only the contribution that each removed boundary site originally made to the selected conventional cell.

  • Identify the geometric object: edge, face diagonal, body diagonal or plane.
  • List occupied coordinates lying exactly on it.
  • Apply corner/edge/face/internal sharing fractions.
  • Subtract species separately and reduce the final ratio.
6
Worked example

Remove one face diagonal

A cell has A at all corners, B at all face centres and C at the body centre. Remove the sites lying on one face diagonal. Find the remaining A:B:C ratio.

  1. Initially A=1, B=3, C=1.
  2. The chosen face diagonal contains two corner A sites and one face-centre B site.
  3. Remaining A =1−2(1/8)=3/4=1-2(1/8)=3/4=1−2(1/8)=3/4; B =3−1/2=5/2=3-1/2=5/2=3−1/2=5/2; C =1=1=1.
  4. Multiply by 4.
The remaining ratio is A:B:C =3:10:4=3:10:4=3:10:4.
