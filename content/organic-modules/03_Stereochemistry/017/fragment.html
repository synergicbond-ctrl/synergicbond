14. Counting stereoisomers

14.1 The two formulae and their proofs

Case A: no symmetry. If the molecule has n stereocentres and no symmetry relating them (different ends, or all centres different), each centre can be R or S independently: 2n stereoisomers, forming 2n−1 enantiomeric pairs. No meso form is possible. Case B: symmetrical molecule (both halves constitutionally identical, like HOCH2(CHOH)nCH2OH or tartaric acid). Here is the proof, which is worth knowing.

  • Describe each stereoisomer by a bit string b = (b1, ..., bn) read from one end: bi = 0 or 1 says on which side (left or right in a Fischer projection) the OH sits at centre i. There are 2n strings.
  • Turning the molecule through 180° in the plane (allowed, it is the same molecule) reads the chain from the other end and swaps left and right at every centre: b → complement of reversed b. Strings related this way are the same compound.
  • The mirror image of b is the complement of b (every left/right swapped, order kept).
  • The number of different compounds is the number of orbits under the 180° operation. Strings fixed by the operation satisfy bi ≠ bn+1−i for all i: there are 2n/2 of them for even n and none for odd n (the central bit would have to differ from itself).
  • Number of compounds = (2n + number of fixed strings)/2.
Formula Symmetrical, n even: total = 2n−1 + 2n/2−1 meso = 2n/2−1 enantiomeric pairs = 2n−1 − 2n/2−1
Formula Symmetrical, n odd: total = 2n−1 meso = 2(n−1)/2 enantiomeric pairs = 2n−2 − 2(n−3)/2
> Meso compounds are those equal to their own mirror image: complement(b) is related to b by the 180° operation, which means b is a palindrome (b = reverse of b): 2⌈n/2⌉ palindromes, each meso compound being represented by two of them (b and its complement): meso = 2⌈n/2⌉−1.

14.2 Which formula? A flowchart in words

  • 1. Count the stereocentres n (carbons with four different groups; ring carbons only if the ring paths differ).
  • 2. Is the molecule symmetric (could a mirror plane or C2 axis swap two halves)? If no: 2n.
  • 3. If yes: n even → 2n−1 + 2n/2−1; n odd → 2n−1.
  • 4. Add geometrical isomers (E/Z or ring cis/trans) if present; multiply when independent (stereocentre × double bond), but beware of symmetry that links them.
  • 5. Subtract nothing for "optically inactive" unless the question asks only for active forms.
Example 41 Main

Count stereoisomers: acyclic

Find the total number of stereoisomers, the number of enantiomeric pairs and the number of meso forms of: (a) 2,3-dibromobutane; (b) 2,3-dibromopentane; (c) 2,3,4-tribromopentane; (d) 2,3,4,5-tetrabromohexane; (e) 2,3,4,5-tetrahydroxyhexanedioic acid.

Show solution
  1. (a) Symmetric, n = 2: total 2 + 1 = 3; pairs 1; meso 1.
  2. (b) 2,3-Dibromopentane: ends CH3 and C2H5 differ: unsymmetrical, n = 2: 4; pairs 2; meso 0.
  3. (c) n = 3, symmetric: 4; meso 21 = 2; pairs 1 (the (2R,4R)/(2S,4S) pair).
  4. (d) n = 4, symmetric: 8 + 2 = 10; meso 2; pairs 4.
  5. (e) 2,3,4,5-Tetrahydroxyhexanedioic acid (the aldaric acids, e.g. glucaric, mucic acid): symmetric, n = 4: 10 total, 2 meso (mucic acid is meso).
Example 42 Adv

Cyclic compounds

Count the stereoisomers: (a) 1,2,3-trimethylcyclopropane and 1,2,3,4-tetramethylcyclobutane; (b) cyclohexane-1,2,3-triol; (c) cyclohexane-1,2,4-triol; (d) cyclohexane-1,3,5-triol; (e) hexachlorocyclohexane C6H6Cl6; (f) cyclohexane-1,2,3,4,5,6-hexol (inositol).

Show solution
  1. (a) 1,2,3-Trimethylcyclopropane: all-cis and (cis,trans)-forms: 2 stereoisomers, both achiral. 1,2,3,4-Tetramethylcyclobutane: 4, all achiral.
  2. (b) Cyclohexane-1,2,3-triol: 4 (2 meso + 1 enantiomeric pair).
  3. (c) Cyclohexane-1,2,4-triol: three different centres, no symmetry: 23 = 8 (4 enantiomeric pairs).
  4. (d) Cyclohexane-1,3,5-triol: only 2 stereoisomers (all-cis and cis,trans), both achiral.
  5. (e) Hexachlorocyclohexane (the pesticide BHC): 9 stereoisomers, 7 achiral + 1 enantiomeric pair (the α-isomer is the chiral one; γ-BHC is lindane).
  6. (f) Inositol: also 9 (7 meso and one enantiomeric pair, the pair being the (+)- and (−)-chiro-inositols; myo-inositol is one of the meso forms).
Example 43 Adv

Stereocentres plus double bonds

How many stereoisomers does each have? (a) pent-3-en-2-ol, CH3CH=CH–CH(OH)–CH3; (b) 4-chlorohepta-2,5-diene, CH3CH=CH–CHCl–CH=CH–CH3; (c) octa-2,6-diene-4,5-diol, CH3CH=CH–CH(OH)–CH(OH)–CH=CH–CH3.

Show solution
  1. (a) One stereocentre (the carbinol carbon) and one E/Z double bond: 2 × 2 = 4.
  2. (b) The central carbon carries H, Cl and two arms of identical constitution; it is a stereocentre only when the arms differ in geometry. (E,E) and (Z,Z): the centre is not stereogenic, one achiral compound each: 2. (E,Z) (identical to (Z,E) by symmetry): the arms differ, so the centre is stereogenic: an enantiomeric pair: 2. Total 4 (2 achiral + 1 pair).
  3. (c) Symmetric in the two halves, with two stereocentres and two double bonds. The enumeration gives 10 stereoisomers (8 chiral, 2 meso).

14.3 Derived counts that questions ask for

Given a compound with n different (unsymmetrical case) stereocentres: total 2n; optically active forms = 2n (all chiral); racemic mixtures = 2n−1; diastereomers of one given stereoisomer = 2n − 2; enantiomer of a given isomer: 1. For a symmetrical molecule with n even: optically active forms = total − meso = (2n−1 + 2n/2−1) − 2n/2−1 = 2n−1. Check with n = 4: total 10, meso 2, chiral 8 = 23 ✓; with n = 2: total 3, meso 1, chiral 2 = 21 ✓.

Formula Symmetrical, n even: optically active forms = 2n−1; racemic modifications = 2n−2; meso 2n/2−1. Symmetrical, n odd: active = 2n−1 − 2(n−1)/2.
Example 44 Main

Optically active forms

How many optically active stereoisomers does 2,3,4,5-tetrabromohexane have? How many racemic mixtures can be made?

Show solution
  1. n = 4, symmetric: total 10, meso 2, active 8: 8 optically active forms, forming 4 racemic modifications.
Example 45 Adv

Diastereomers of a given isomer

For an unsymmetrical molecule with three different stereocentres (2,3,4-tribromohexane), how many diastereomers does one particular stereoisomer have?

Show solution
  1. Total stereoisomers 23 = 8. Remove the isomer itself and its enantiomer: 8 − 2 = 6 diastereomers.

14.4 Summary sheet: counting

  • Unsymmetrical n centres: 2n; pairs 2n−1; diastereomers of a given isomer 2n−2.
  • Symmetrical n even: 2n−1 + 2n/2−1 (meso 2n/2−1); n odd: 2n−1 (meso 2(n−1)/2).
  • Rings: do the enumeration; 1,2- and 1,3- (not cyclobutane) give 3; 1,4- gives 2; 1,3,5-trisubstituted gives 2; hexa-substituted cyclohexane with six identical groups gives 9.
  • Add E/Z for each stereogenic double bond.
  • Always check symmetry before choosing a formula.
