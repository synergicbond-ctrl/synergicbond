## C. Reaction Register — Group 15 (pp. 448–470)

Grouped by reaction class. All balanced as printed unless flagged.

**Hydrolysis (differentiated by element — a single table replaces four facts)**
- NCl₃ + 4H₂O → NH₄OH + 3HOCl **(note: N is the *positive* end, so N goes to NH₃ not HOCl)**
- PCl₃ + 3H₂O → H₃PO₃ + 3HCl · AsCl₃ + 3H₂O → H₃AsO₃ + 3HCl
- SbCl₃ + H₂O → SbO⁺ + 3Cl⁻ + 2H⁺ · BiCl₃ + H₂O → BiO⁺ + 3Cl⁻ + 2H⁺
- **NF₃ does not hydrolyse at all** (cf. CF₄) — reacts only if sparked with water vapour
- PCl₅ + 4H₂O → H₃PO₄ + 5HCl; **equimolar** → POCl₃ + 2HCl
- CaNCN + 5H₂O → CaCO₃ + 2NH₄OH
- NH₂CONH₂ + 2H₂O → (NH₄)₂CO₃
- N₂O₃ + H₂O → 2HNO₂ · N₂O₄ + H₂O → HNO₃ + HNO₂ · N₂O₅ + H₂O → 2HNO₃

**Thermal decomposition (anion-dependent)**
- NH₄Cl → NH₃ + HCl · (NH₄)₂SO₄ → 2NH₃ + H₂SO₄
- NH₄NO₂ → N₂ + 2H₂O · NH₄NO₃ (280 °C) → N₂O + 2H₂O · **2NH₄NO₃ (>300 °C) → 2N₂ + O₂ + 4H₂O**
- (NH₄)₂Cr₂O₇ → N₂ + 4H₂O + Cr₂O₃
- 2NaNO₃ → 2NaNO₂ + O₂ · NaNO₃ + Pb → NaNO₂ + PbO
- 2Pb(NO₃)₂ → 2PbO + 4NO₂ + O₂
- 2HN₃ → H₂ + 3N₂ (explosive)

**Disproportionation**
- 4[NH₂OH·H]⁺ → N₂O + 2NH₄⁺ + 2H⁺ + 3H₂O (slow, acid)
- 3NH₂OH → N₂ + NH₃ + 3H₂O (rapid, alkaline)
- 2HNO₂ → NO₂ + NO + H₂O
- P₄ + 3NaOH + 3H₂O → PH₃ + 3NaH₂PO₂

**Redox — hydrazine**
- N₂H₄ + O₂ → N₂ + 2H₂O, ΔH = −621 kJ mol⁻¹
- N₂H₄ + 2I₂ → 4HI + N₂ · N₂H₄ + 2O₂ → 2H₂O₂ + N₂ · N₂H₄ + 2CuSO₄ → Cu + N₂ + 2H₂SO₄
- **N₂H₄ + Zn + 2HCl → 2NH₃ + ZnCl₂** (hydrazine *reduced*, i.e. oxidised partner)

**Raschig synthesis (with both side reactions)**
- NH₃ + NaOCl → NH₂Cl + NaOH (fast); 2NH₃ + NH₂Cl → N₂H₄ + NH₄Cl (slow)
- side: N₂H₄ + 2NH₂Cl → N₂ + 2NH₄Cl; 3NH₂Cl + 2NH₃ → N₂ + 3NH₄Cl

**Azide synthesis**
- N₂O + 2NaNH₂ → NaN₃ + NH₃ + NaOH (190 °C, anhydrous)
- 6HN₃ + 4Li → 4LiN₃ + 2NH₃ + 2N₂ **(no H₂ evolved — unlike any normal acid + metal)**
- NaN₃ + H₂S + H₂O → NH₃ + N₂ + S + NaOH (analysis)

**Complex formation**
- [Ru(NH₃)₅H₂O]²⁺ + N₂ → [Ru(NH₃)₅N₂]²⁺ (first dinitrogen complex, 1965)
- Ni(CO)₄ + 4PF₃ → Ni(PF₃)₄ + 4CO
- [Fe(CO)₅] + 2NO → [Fe(CO)₂(NO)₂] + 3CO **(NO is a 3-electron donor — 2 NO replace 3 CO)**
- [Cr(CO)₆] + 4NO → [Cr(NO)₄] + 6CO

**Industrial**
- CaC₂ + N₂ → CaNCN + C (1100 °C)
- 2NH₃ + CO₂ → NH₂COONH₄ → CO(NH₂)₂ + H₂O (180–200 °C, high P)
- 3Ca₃(PO₄)₂·CaF₂ + 7H₂SO₄ → 3Ca(H₂PO₄)₂ + 7CaSO₄ + 2HF
- 3Ca₃(PO₄)₂·CaF₂ + 14H₃PO₄ → 10Ca(H₂PO₄)₂ + 2HF
- 2NH₃ + CO₂ + H₂O → (NH₄)₂CO₃; + CaSO₄ → CaCO₃ + (NH₄)₂SO₄

**Nitryl/nitrosyl halide formation**
- 2NO₂ + F₂ → 2NO₂F · 2NO₂ + Cl₂ → 2NO₂Cl · 2NO + Cl₂ → 2NOCl
- 2NO₂ + 4HCl → 2NOCl + Cl₂ + 2H₂O · NO₂ + CO → CO₂ + NO
- N₂O₃ + 2HClO₄ → 2NO[ClO₄] + H₂O
- N₂O₅ + NaCl → NaNO₃ + NO₂Cl

## E. MO-Theory Register

Where MO theory does real explanatory work (spec Phase 8):

| # | Case | The MO argument |
|---|---|---|
| E1 | **NO** | 11 outer electrons; extra electron in **π\*2p** → bond order 2½; removing it gives NO⁺ with order 3, and the bond **contracts 1.15 → 1.06 Å.** Quantitative confirmation. |
| E2 | **HN₃ vs N₃⁻** | N₃⁻ symmetric, both bonds 1.16 Å. Adding H's electron **forces occupation of an antibonding MO**, so HN₃ has two *different* N–N lengths. |
| E3 | **NO₂ ⇌ N₂O₄** | odd-electron paramagnetic monomer pairing to diamagnetic dimer. |
| E4 | **N₂ vs CO/CN⁻/NO⁺** | isoelectronic but N₂'s bonds are **non-polar**, hence far less reactive. |
| E5 | **O₂ paramagnetism** | already in §11.3. |
| E6 | **d-orbital contraction** | 3d of free P is far too diffuse to bond; **electronegative ligands contract it to 3s/3p size**. This is the honest basis for the "sp³d" label — and the limit of it. |
| E7 | **Donor power of MH₃** | as ∠ → 90°, M–H uses near-pure p, so the lone pair sits in a **spherical s orbital** — larger, less directional, a poor σ donor. Plus 4d/5d too diffuse for π back-bonding. |
| E8 | **NF₃ low dipole** | lone-pair moment **partly cancelled** by three electronegative F; explains weak donor power. |
| E9 | **NO as 3-electron donor** | 2 NO replace 3 CO. |
| E10 | Xenon fluorides | pending §10.73. |
