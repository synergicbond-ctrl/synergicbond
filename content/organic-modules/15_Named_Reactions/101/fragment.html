Block G. Multi-step syntheses

Practice 140 Synthesis

Benzene → benzoic acid in two steps (not via a nitrile).

Show answer
  1. (i) CH3Cl/AlCl3 → toluene. (ii) KMnO4, OH−, heat, then H+ → benzoic acid (benzylic oxidation needs a benzylic H).
Practice 141 Synthesis

Benzene → acetanilide.

Show answer
  1. HNO3/H2SO4 → nitrobenzene; Sn/HCl → aniline; (CH3CO)2O (or CH3COCl/pyridine) → acetanilide.
Practice 142 Synthesis

Ethanol → propanoic acid.

Show answer
  1. Ethanol → PBr3 → bromoethane → KCN → propanenitrile → H3O+, Δ → propanoic acid (chain +1).
Practice 143 Synthesis

Ethanol → butan-2-ol.

Show answer
  1. Split ethanol: (a) PCC → ethanal; (b) PBr3 → bromoethane → Mg/ether → C2H5MgBr. Then CH3CHO + C2H5MgBr, H3O+ → CH3CH(OH)CH2CH3, butan-2-ol.
Practice 144 Synthesis

Propene → propan-1-ol and → propan-2-ol (one reagent set each).

Show answer
  1. Propan-1-ol: BH3·THF, then H2O2/NaOH (anti-Markovnikov). Propan-2-ol: dilute H2SO4/H2O (Markovnikov), or Hg(OAc)2/H2O then NaBH4.
Practice 145 Synthesis

Propanone → 2-methylbutan-2-ol.

Show answer
  1. CH3COCH3 + C2H5MgBr (from bromoethane + Mg), then H3O+ → (CH3)2C(OH)CH2CH3.
Practice 146 Synthesis

Benzaldehyde → 1-phenylethanol, and then → styrene.

Show answer
  1. PhCHO + CH3MgBr, H3O+ → PhCH(OH)CH3; H2SO4, Δ (or Al2O3) → styrene (E1, benzylic cation).
Practice 147 Synthesis

Bromobenzene → benzoic acid (two steps), then → benzoyl chloride.

Show answer
  1. (i) Mg, dry ether → PhMgBr; CO2, then H3O+ → benzoic acid; (ii) SOCl2 → benzoyl chloride.
Practice 148 Synthesis

Ethyne → ethanoic acid.

Show answer
  1. HC≡CH + H2O, HgSO4/H2SO4 (Kucherov) → CH3CHO; then Tollens' reagent (or K2Cr2O7/H+) → CH3COOH.
Practice 149 Synthesis

Toluene → phenylethanoic acid.

Show answer
  1. NBS, hν (or Br2, hν) → benzyl bromide; KCN → PhCH2CN; H3O+, Δ → PhCH2COOH.
Practice 150 Synthesis

Benzene → p-nitrobenzoic acid.

Show answer
  1. CH3Cl/AlCl3 → toluene; HNO3/H2SO4 → o- and p-nitrotoluene (separate); KMnO4, OH−; H+ → p-nitrobenzoic acid. (Nitrate before oxidation: –COOH would direct meta.)
Practice 151 Synthesis

Aniline → fluorobenzene and → iodobenzene.

Show answer
  1. NaNO2/HCl, 273 K → PhN2+Cl−. Fluoro: HBF4 then heat (Balz–Schiemann). Iodo: KI (no Cu needed).
Practice 152 Synthesis

Cyclohexanone → 1-methylcyclohexene.

Show answer
  1. CH3MgBr, then H3O+ → 1-methylcyclohexanol; H2SO4, Δ → 1-methylcyclohexene (Saytzeff, endocyclic).
Practice 153 Synthesis

Diethyl malonate → butanedioic (succinic) acid.

Show answer
  1. NaOEt, then ClCH2COOEt (SN2) → (EtOOC)2CH–CH2COOEt; hydrolysis (aq. NaOH, then H3O+), heat (–CO2) → HOOC–CH2CH2–COOH.
Practice 154 Synthesis

Ethyl acetoacetate → heptan-2-one.

Show answer
  1. NaOEt, then CH3CH2CH2CH2Br; dilute NaOH then H3O+, Δ → CH3COCH2C4H9, heptan-2-one.
Practice 155 Synthesis

Ethyl acetoacetate + CH3I (one equivalent), then conc. NaOH, reflux; then H3O+. Give the products.

Show answer
  1. Alkylated ester CH3COCH(CH3)COOEt. Concentrated NaOH causes acid cleavage at the C–C bond: CH3COOH + CH3CH2COOH (two acids), not the ketone.
Practice 156 Synthesis

Benzene → biphenyl, and chlorobenzene → toluene (Wurtz–Fittig).

Show answer
  1. Benzene → Br2/FeBr3 → bromobenzene; Na, dry ether (Fittig) → biphenyl. Chlorobenzene + CH3Cl + 2 Na (Wurtz–Fittig) → toluene.
Practice 157 Synthesis

Benzaldehyde → 3-phenylpropanoic acid.

Show answer
  1. Perkin: (CH3CO)2O, CH3COONa, 453 K → cinnamic acid; H2, Pd/C → PhCH2CH2COOH.
Practice 158 Synthesis

Ethanal → buta-1,3-diene.

Show answer
  1. Dilute NaOH → 3-hydroxybutanal; NaBH4 → butane-1,3-diol; Al2O3, 570 K (or H2SO4, Δ) → buta-1,3-diene.
Practice 159 Synthesis

Propanone → 4,4-dimethylpentan-2-one (via mesityl oxide).

Show answer
  1. Aldol/dehydration (Ba(OH)2, Δ) → mesityl oxide, (CH3)2C=CH–CO–CH3; (CH3)2CuLi (1,4-addition), then H3O+ → (CH3)3C–CH2–CO–CH3.
Practice 160 Synthesis

Aniline → 1,3,5-tribromobenzene.

Show answer
  1. Br2/H2O (excess) → 2,4,6-tribromoaniline; NaNO2/HCl, 273 K → diazonium; H3PO2 (or CH3CH2OH, Δ) → 1,3,5-tribromobenzene.
Practice 161 Synthesis

Cyclohexene → hexanedioic acid, and from it a five-membered ketone.

Show answer
  1. Hot, conc. KMnO4 (or O3/H2O2) cleaves C=C → HOOC(CH2)4COOH. Heating with Ba(OH)2 (then distilling) gives cyclopentanone. (Or esterify and use the Dieckmann cyclisation.)
Practice 162 Synthesis

Phenol → coumarin (via salicylaldehyde).

Show answer
  1. Reimer–Tiemann (CHCl3/NaOH, then H+) → salicylaldehyde; Perkin with (CH3CO)2O/CH3COONa, heat → o-hydroxycinnamic acid, which lactonises (cis isomer) → coumarin.
