4. Three-Dimensional Packing from Square Layers

  • AAA stacking of square layers gives simple cubic: CN 6, PE ≈52%.
  • A shifted square-layer arrangement gives BCC-like ABAB stacking: CN 8, PE ≈68%.

5. Three-Dimensional Packing from Hexagonal Close-Packed Layers

◆Concept

Place layer B so its spheres occupy one set of triangular depressions of layer A. Between A and B, tetrahedral and octahedral voids are created.

For the third layer there are two key possibilities:

Third-layer choiceSequence3D structureCNPE
Cover tetrahedral-hole positions so layer 3 repeats AABAB…HCP1274.05%
Occupy the alternate set so layer 3 is new CABCABC…CCP = FCC1274.05%

6. Ideal HCP c/a and Volume Derivation

∑Formula

Ideal HCP c/a = √(8/3) ≈ 1.633.

◆Concept

For touching spheres a=2r and c=4r√(2/3). The regular-hexagon base area is (3√3/2)a²=6√3r².

∑Formula

V_HCP = 24√2 r³.

◆Concept

The conventional HCP prism contains 6 atoms, so occupied volume = 6(4/3πr³)=8πr³.

∑Formula

η_HCP = π/(3√2) = 0.7405 = 74.05%.

7. Diamond Packing Fraction

◆Concept

The source also evaluates diamond as an FCC framework with half the tetrahedral sites occupied by identical carbon atoms. Z=8 and nearest-neighbour contact gives r=√3a/8.

∑Formula

Diamond packing fraction = π√3/16 ≈ 0.34, so void space ≈66%.

⚠JEE Advanced traps & edge cases

  • HCP and CCP have the same packing efficiency and CN but different stacking sequences.
  • BCC is not a maximum close-packed structure despite its relatively high coordination.
  • 2D hexagonal packing efficiency (~90.7% area) must not be confused with 3D HCP packing efficiency (~74.05% volume).

▶Solved examples

Worked example 1

Example 1 — Integer/ratio

Find the ratio of FCC packing fraction to SC packing fraction.

  1. FCC = π/(3√2).
  2. SC = π/6.
  3. Divide: [π/(3√2)]/(π/6)=2/√2.

Ratio = √2.

Worked example 2

Example 2 — Multi-correct

Which are correct? (A) HCP=ABAB (B) CCP=ABCABC (C) both CN=12 (D) HCP packs more efficiently than CCP.

  1. A true.
  2. B true.
  3. C true.
  4. D false; both are 74.05%.

Correct: A, B, C.
