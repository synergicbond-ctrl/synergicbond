SIR-MS-01 [Multi-step (acidity)]

Phenol pKₐ 10.0 and p-nitrophenol pKₐ 7.14 (Ref. [2]). Find the ratio of Kₐ values and explain why the NO₂ group at the para position is responsible.

Worked solution
  1. ΔpKₐ = 10.0 − 7.14 = 2.86.
  2. Kₐ ratio = 10^2.86 ≈ 7.2 × 10² (about 720 times stronger).
  3. The phenoxide charge is delocalised onto NO₂ through the ring (−M), an effect that needs the nitro group to stay coplanar with the ring.
  4. Check: 4-chlorophenol (pKₐ 9.38, Ref. [2]) differs from phenol by only 0.62, which fits inductive-only withdrawal.

Answer: ≈ 7 × 10² (ratio); −M effect of coplanar NO₂.

SIR-MS-02 [Multi-step (acidity)]

Benzoic acid pKₐ 4.19 and p-nitrobenzoic acid pKₐ 3.41 (Ref. [1]). Compute σ and compare with the tabulated σₚ(NO₂) = 0.81 (Ref. [3], Table 4.5).

Worked solution
  1. σ(from pKₐ) = 4.19 − 3.41 = 0.78.
  2. Tabulated σₚ(NO₂) = 0.81.
  3. Difference 0.03: within the expected rounding of pKₐ values. The check confirms that p-NO₂ acts by its full σₚ (resonance + induction) on the carboxylate.

Answer: σ ≈ 0.78, consistent with σₚ = 0.81.

SIR-MS-03 [Multi-step (basicity)]

Using Ref. [1], Table 19-3: aniline pKₐH 4.60, N-methylaniline 4.79, N,N-dimethylaniline 5.06. Explain the trend and identify what SIR would change.

Worked solution
  1. Each N-methyl adds electron density (+I), so basicity rises: 4.60 → 4.79 → 5.06.
  2. The lone pair is still conjugated with the ring in all three, so the trend is inductive, not steric.
  3. If two ortho methyl groups were added to N,N-dimethylaniline, SIR would twist NMe₂ out of plane and remove conjugation: the base would become stronger than 5.06 (an SIR prediction; no sourced pKₐH for that compound, so no number is given).

Answer: 4.60 < 4.79 < 5.06; SIR would raise basicity further (qualitative).

SIR-MS-04 [Multi-step (dipole)]

Group moments: μ(C₆H₅Cl) = 1.70 D, μ(C₆H₅NO₂) = 4.00 D, both with the negative end on the substituent. Compute the dipole moment of p-chloronitrobenzene (para: 180° between outward axes).

Worked solution
  1. Both vectors point outward. Para axes differ by 180°.
  2. μ = |4.00 − 1.70| = 2.30 D.
  3. Check: the meta isomer (120°) gives 3.48 D, the ortho (60°) gives about 5.0 D; para is smallest, as expected.

Answer: 2.30 D

SIR-MS-05 [Multi-step (intermediate stability)]

Compare the stabilisation of the benzyl cation (resonance with the ring) with the stabilisation of a planar vs twisted ring substituent. Use hydride-ion affinities from the sheet passage (CH₃⁺ 312, benzyl 238 kcal mol⁻¹; given data) to quantify the stabilisation, then state the SIR condition that must hold.

Worked solution
  1. Stabilisation of benzyl relative to methyl = 312 − 238 = 74 kcal mol⁻¹ (passage data).
  2. Benzyl stabilisation needs the ring π-system to overlap with the empty p orbital (coplanar CH₂⁺ and ring).
  3. If a bulky group forces the CH₂⁺ out of the ring plane, overlap falls as cos θ and the stabilisation falls toward the inductive value only.

Answer: 74 kcal mol⁻¹ (given data); SIR condition: coplanarity required.

SIR-MS-06 [Multi-step (conditions)]

Explain, in order, why (a) an ortho-substituted benzoic acid and (b) a para-substituted one differ in ionisation strength, using only the sourced facts: ortho steric inhibition of resonance and σₚ values.

Worked solution
  1. (a) Ortho substituents can twist COOH out of plane; loss of ring–carboxyl conjugation changes the acid strength (the direction depends on the group; no sourced ortho pKₐ for 2,6-disubstituted acids is quoted here).
  2. (b) Para substituents keep coplanarity, so σₚ applies directly (e.g. NO₂ σₚ = 0.81 Ref. [3]; pKₐ 3.41 Ref. [1]).
  3. So steric twist is the only difference between the two cases.

Answer: Ortho: steric (SIR, direction group-dependent); para: σₚ (fully conjugated).
