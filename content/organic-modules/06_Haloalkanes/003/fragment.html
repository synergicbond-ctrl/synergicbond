2. Nomenclature

Common (alkyl halide) names: alkyl group + halide (ethyl chloride, isopropyl bromide, tert-butyl iodide, benzyl chloride, allyl bromide, vinyl chloride, methylene chloride = CH2Cl2, chloroform = CHCl3, carbon tetrachloride, iodoform = CHI3, ethylene dibromide = BrCH2CH2Br, ethylidene chloride = CH3CHCl2). IUPAC (substitutive) names: the halogen is a prefix (fluoro, chloro, bromo, iodo) to the parent chain; halogens never get priority over the chain numbering unless there is a choice, and rank equally with alkyl groups. Number to give the lowest locant set to all substituents (halo and alkyl together); if there is still a tie, the first cited substituent in alphabetical order gets the lowest number.

1-Chloro-2-methylpropane 2-Bromo-2-methylbutane 3-Bromoprop-1-ene (allyl bromide) 1-Chloro-2-methylbenzene (o-chlorotoluene) (Chloromethyl)benzene (benzyl chloride) 1,2-Dibromoethane
Trap When both a halogen and a double bond are present, the double bond gets the lower locant if there is a choice (halogens are only prefixes). CH3–CHBr–CH=CH2: 3-bromobut-1-ene, not 2-bromobut-3-ene. If locants tie, the substituent cited first alphabetically (bromo, chloro, then methyl) gets the lower number. Example: BrCH2CH2CH2Cl is 1-bromo-3-chloropropane (locants {1,3} either way, so bromo gets 1). For CH3CH2CHBrCH2Cl the lower locant set {1,2} decides, so it is 2-bromo-1-chlorobutane.
Formula Halobenzenes: fluorobenzene, chlorobenzene, bromobenzene, iodobenzene. Disubstituted: ortho (1,2), meta (1,3), para (1,4); with three or more substituents use numbers.
Example 3 Main

Naming

Give IUPAC names of: (a) CH3CH(Cl)CH(CH3)CH2CH3 (b) (CH3)3C–CH2Br (c) BrCH2–CH=CH–CH3 (d) ClCH2–C≡C–CH3.

Show solution
  1. (a) Longest chain is 5 carbons, with Cl at C2 and CH3 at C3: 2-chloro-3-methylpentane.
  2. (b) Neopentyl bromide: 1-bromo-2,2-dimethylpropane.
  3. (c) 1-bromobut-2-ene (crotyl bromide, an allylic bromide). The double bond is numbered before the bromo prefix only if the numbering from the other end is no better, here C=C gets locant 2 in either direction, so the halogen gets 1.
  4. (d) 1-chlorobut-2-yne.
