1.1 What a name must do

Definition. A chemical name is a sentence that lets a reader redraw one, and only one, structure. Because millions of organic compounds exist, names cannot be memorised one by one; they have to be generated by a grammar. The grammar adopted internationally is IUPAC nomenclature.

Three kinds of name occur.

  • Trivial names (acetone, urea, toluene, chloroform) were given before structures were known and encode nothing; each must be learned (Part 9).
  • Common (derived) names (isopropyl alcohol, ethyl methyl ketone, di-n-butyl ether) name the groups attached to a functional-group word. They are convenient for small molecules and unworkable for large ones.
  • Systematic names are produced by a fixed procedure (parent → suffix → prefixes → locants), so that each structure has one name and each name one structure.

This module teaches substitutive nomenclature, the main systematic method: one functional group is chosen as the principal group and expressed as a suffix; every other group is a prefix.

Why It Happens The rules look arbitrary but each answers a real ambiguity. Choosing one principal group removes the question of which group to cite as the suffix; the "lowest locants" rule removes the question of which end of the chain to number from; alphabetical citation fixes the order in which prefixes are written. Without all three, one structure would have many names.
IMP Every IUPAC name answers four questions, in the order in which the name is built: (1) which group is senior, and so becomes the suffix? (2) which chain or ring carries it (the parent)? (3) how is the parent numbered (the locants)? (4) which groups hang off it (the prefixes, in alphabetical order)?
