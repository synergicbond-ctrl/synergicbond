◆Concept

This part gives a canonical unit-cell formula problem and then removes atoms along a face diagonal or from an entire face. Coordinate tracking is the safest method.

1. Base Cell

◆Concept

Let A occupy all corners, B all face centres and C the body centre.

∑Formula

A=1, B=3, C=1 ⇒ AB₃C.

★Base result

Original effective formula = AB₃C.

2. Remove Atoms Along One Face Diagonal

◆Concept

Choose the face z=0 and diagonal y=x. The occupied positions on that diagonal are A at (0,0,0) and (1,1,0), and B at (1/2,1/2,0).
  • A removed = 2×1/8 = 1/4, so A remaining = 3/4.
  • B removed = one face-centre contribution = 1/2, so B remaining = 5/2.
  • C remains 1.

∑Formula

A:B:C = 3/4 : 5/2 : 1 = 3 : 10 : 4.

★Result

Modified formula = A₃B₁₀C₄.

3. Remove Atoms Along One Entire Face

◆Concept

Again choose z=0. Remove four corner A contributions on that face and the B face-centre on that face.
  • A removed = 4×1/8 = 1/2 → A remaining = 1/2.
  • B removed = 1/2 → B remaining = 5/2.
  • C remains 1.

∑Formula

A:B:C = 1/2 : 5/2 : 1 = 1 : 5 : 2.

★Result

Modified formula = AB₅C₂.

4. Coordinate-Tracking Algorithm

  • Write the occupied fractional coordinates for every species.
  • Write the geometrical equation of the removed line/plane/axis.
  • Identify which occupied coordinates satisfy that equation.
  • Subtract sharing-weighted contributions, not visible sphere counts.
  • Only then reduce to the empirical ratio.

⚠JEE Advanced traps & edge cases

  • “Remove a face” means remove contributions belonging to that specified boundary face, not every symmetry-equivalent face.
  • A face diagonal can pass through a face-centred atom.
  • Two corner atoms removed from one face diagonal reduce A by 2/8, not by 2 full atoms.

▶Solved examples

Worked example 1

Example 1 — Source reconstruction

For A(corners), B(face centres), C(body centre), remove one face diagonal.

  1. A=1−2/8=3/4.
  2. B=3−1/2=5/2.
  3. C=1.
  4. Multiply by 4.

A₃B₁₀C₄.

Worked example 2

Example 2 — Plane removal

For the same cell, remove all atoms on one face.

  1. A=1−4/8=1/2.
  2. B=3−1/2=5/2.
  3. C=1.
  4. Multiply by 2.

AB₅C₂.
