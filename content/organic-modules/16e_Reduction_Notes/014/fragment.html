Practice 1 L1 Foundation

Which transformation of the organic substrate is a reduction?

(A) CH3CH2OH → CH3CHO

(B) CH3COOH → CH3CH2OH

(C) CH2=CH2 → CH3CH2OH (H2O, H+)

(D) C6H5CH3 → C6H5COOH

Show answer
  1. Follow the oxidation number of the functional carbon in each step.
  2. (A) CH2OH (−1) → CHO (+1): oxidation. (C) Hydration leaves the average oxidation number of carbon unchanged (−2 before and after): not a redox step. (D) CH3 (−3) → COOH (+3): oxidation.
  3. (B) COOH (+3) → CH2OH (−1): the carbon gains electrons, so this is a reduction.

Answer: B

Practice 2 L1 Foundation

The functional carbon of acetone is converted into the carbinol carbon of propan-2-ol. By how many units does its oxidation number decrease?

Show answer
  1. Ketone carbon: C=O counts +2, two C–C bonds contribute 0, so the oxidation number is +2.
  2. Alcohol carbon: C–O counts +1, C–H counts −1, two C–C contribute 0, so the oxidation number is 0.
  3. Decrease = 2 − 0 = 2, equal to the two electrons (2[H]) required.

Answer: 2

Practice 3 L1 Foundation

Pent-1-en-4-yne is shaken with excess H2 over Pd/C (1 atm, 25 °C) until uptake stops. How many moles of H2 are absorbed per mole?

Show answer
  1. Both the C=C (1 mol H2) and the C≡C (2 mol H2) are reduced over Pd/C when no poison is present.
  2. Total = 1 + 2 = 3 mol, giving pentane.

Answer: 3

Practice 4 L1 Foundation

Practice 7 L1 Foundation

Practice 28 L2 Main

4-tert-Butylcyclohexanone is reduced either with NaBH4 or with L-Selectride. Which statements are correct?
