3.1 Alkenes and alkynes

Definition. A hydrocarbon containing C=C is an alkene and one containing C≡C is an alkyne; the multiple bond is expressed by the ending of the parent name, not by a prefix.

  • -ane → -ene for a C=C and -ane → -yne for a C≡C. The locant is the lower-numbered carbon of the multiple bond: CH₃CH=CHCH₃ is but-2-ene.
  • The parent chain must contain every multiple bond, even if a longer chain exists that omits one (the 1979/1993 convention; see the note on the 2013 rules below).
  • Numbering: first the principal functional group (if any), then the multiple bond — this ranks above every substituent prefix. Only after the multiple bonds are settled do prefixes decide.
  • Several identical bonds: -diene, -triene, -diyne, and an extra a is inserted after the root for euphony: buta-1,3-diene (not but-1,3-diene), hexa-1,3,5-triene, octa-1,7-diyne. The e of the ending is retained before a consonant (diene) and dropped before a vowel (but-1-en-3-yne, but-2-enal).
  • Both a double and a triple bond: -en- then -yn- in that order (alphabetical), as in pent-1-en-4-yne; the chain is numbered to give the lowest set to both bonds together, and on a tie the double bond gets the lower locant.
Why It Happens The multiple bond ranks above every prefix in numbering because it is part of the parent name itself (the ending -ene or -yne), whereas a prefix only decorates the parent. Parent-defining features are fixed first, decoration afterwards.
IMP For a hydrocarbon the order of numbering decisions is: (1) all multiple bonds together as a set; (2) if still tied, the double bond; (3) all substituent prefixes as a set; (4) the first prefix in alphabetical order.

Example 12 Direct application

Name the alkene.

Show solution
  1. Four-carbon chain containing the C=C.
  2. Number from the end nearest the double bond: C=C at 1; methyl at 3.
  3. The other direction would give the double bond locant 3 (3-ene) and methyl 2: the double bond has priority over prefixes, so it must take the lowest locant, 1.

3-Methylbut-1-ene — never 2-methylbut-3-ene.

Example 14 Standard

Name the diene.

Show solution
  1. Six carbons contain both double bonds: CH₂=CH–CH(CH₃)–CH₂–CH=CH₂.
  2. Locants for the double bonds: {1,5} from either end (symmetric chain). The methyl is on C3 from either end.
  3. Add a after the root: hexa-1,5-diene.

3-Methylhexa-1,5-diene.

Example 15 Direct application

Name the compound — the longest chain does not contain the double bond.

Show solution
  1. The longest carbon chain is the five-carbon CH₃CH₂–C–CH₂CH₃, but that chain does not contain the C=C.
  2. Convention used in JEE answer keys: the parent chain must include the double bond. The longest chain that does is four carbons: CH₂=C–CH₂–CH₃ (but-1-ene).
  3. The remaining CH₂CH₃ is an ethyl branch on C2.

2-Ethylbut-1-ene.

Compare & Distinguish In the 2013 recommendations chain length is applied before unsaturation, so the preferred name is 3-methylidenepentane (longest chain: pentane, with =CH₂ as the substituent methylidene). Under the 1979/1993 convention used in school and JEE problems the double bond stays in the chain: 2-ethylbut-1-ene. The two names describe the same molecule; a problem that gives both among its options is ambiguous unless it states the convention.
